# Changelog

## 1.0.0 - 2026-11-18

Primeira versão, testada no Mapas Culturais 7.8.21.

- Seção **Observações para os inscritos desta fase** no fim de cada fase da aba *Configuração de fases* (coleta de dados, avaliação e publicação final), para o gestor publicar, editar e excluir observações.
- Observação com título (opcional), mensagem em texto simples, uma imagem e até 5 anexos.
- Quadro **[Observação]** na linha do tempo da inscrição, dentro da fase a que pertence, para todos os inscritos daquela fase.
- Imagens e anexos guardados como arquivos privados e entregues por endpoint que confere a permissão (gestor ou inscrito na fase).
- Observações num metadado privado, fora da API pública.
- Validação de tamanho, quantidade e tipo real dos arquivos antes de gravar.
- Teste de API com 30 verificações.
